# Web Fit & Fresh

Landing comercial premium para Fit & Fresh, enfocada en conversión de packs de viandas.

## Objetivo

- Atraer y convertir visitantes en compradores.
- Comunicar ahorro de tiempo, practicidad y comida casera de calidad.
- Mantener una experiencia mobile first, rápida y optimizada para SEO.

## Scripts

- `npm run dev`
- `npm run build`
- `npm run start`

## Estructura

- `src/App.jsx`: composición principal de la landing.
- `src/components/`: componentes reutilizables de sección, CTA, tarjetas y FAQ.
- `src/data/landingData.js`: contenido y textos de la página.
- `src/index.css`: sistema visual completo.
